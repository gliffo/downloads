## Ordine — Prototipo 0.7.3

[Scarica Ordine 0.7.3](https://github.com/gliffo/downloads/raw/refs/heads/main/ordine/Ordine_0.7.3.zip)

Il pacchetto comprende il pannello e i file necessari alla preparazione e installazione. Non comprende il laboratorio di sviluppo o documenti di prova.
